**Tic Tac Toe Application with React**

This is a simple Tic Tac Toe application built using React and configured with Vite for a fast and efficient development experience. The application's styles are implemented using SCSS, providing a clean and modular approach to styling.

**Features**
Interactive Gameplay: Two players can take turns to play Tic Tac Toe.
Win Detection: The app highlights the winner when a player achieves three marks in a row, column, or diagonal.
Draw Detection: Displays a message when the game ends in a draw.
Reset Functionality: Allows players to restart the game with a single click.
Responsive Design: Ensures compatibility across various devices and screen sizes.
Technologies Used
Frontend Framework: React
Build Tool: Vite
Styling: SCSS (Sassy CSS)
